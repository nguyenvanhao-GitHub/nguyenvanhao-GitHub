#### 1. 🏗️ **Core Architecture & Design Patterns**
* **Dependency Injection & IoC:** Thiết kế module hóa cao (Custom Providers, Dynamic Modules, Factory Providers).
* **Guards & Interceptors:** Xử lý xác thực/phân quyền request, logging thời gian thực thi, transform response data chuẩn format.
* **Custom Decorators & Pipes:** Tự viết custom param decorators (e.g., `@CurrentUser()`, `@Roles()`) và Data Transformation/Validation với `class-validator` & `class-transformer`.
* **Exception Filters:** Xây dựng Global/Custom Exception Filters xử lý lỗi tập trung, trả về format chuẩn RESTful.

#### 2. 🛡️ **Authentication, Authorization & Security**
* **Auth Mechanisms:** `@nestjs/passport`, Passport-JWT, Access Token + Refresh Token flow (rotation & revocation qua Redis).
* **Phân quyền nâng cao:** Role-Based Access Control (RBAC), Permission-based guards, CASL authorization.
* **Bảo mật API:** `@nestjs/throttler` (Rate Limiting), Helmet headers, CORS configuration, băm mật khẩu với `Argon2` / `Bcrypt`.

#### 3. 🗄️ **Database & ORM Integration**
* **TypeORM / Prisma:** Entity relations (One-to-Many, Many-to-Many), Database Migrations, Transactions / QueryRunner, Soft-deletes.
* **Mongoose (`@nestjs/mongoose`):** Schema definitions, Sub-documents, Aggregation pipelines.
* **Optimization:** Tối ưu câu truy vấn N+1 problem, indexing, connection pooling.

#### 4. ⚡ **Caching, Background Jobs & Real-time**
* **Caching:** Tích hợp Redis qua `@nestjs/cache-manager`, Cache Invalidation strategy, HTTP Cache Interceptors.
* **Message Queue & Task Scheduling:** Xử lý job bất đồng bộ nền (Email, xuất báo cáo, thông báo) với BullMQ (`@nestjs/bull`), `@nestjs/schedule` (Cron jobs).
* **Event-Driven & WebSockets:** `@nestjs/event-emitter` (Decoupled modules), `@nestjs/websockets` (Socket.io) cho ứng dụng thời gian thực.

#### 5. 🧪 **Documentation, Testing & DevOps**
* **OpenAPI / Swagger:** Tự động tạo tài liệu API chuẩn và tương tác trực tiếp với `@nestjs/swagger`.
* **Testing:** Unit test Services/Controllers với Jest (`@nestjs/testing`), E2E testing với Supertest.
* **Configuration & Container:** Quản lý đa môi trường bằng `@nestjs/config` (Joi/Zod validation), Dockerize NestJS App (Multi-stage build tối ưu kích thước image).
